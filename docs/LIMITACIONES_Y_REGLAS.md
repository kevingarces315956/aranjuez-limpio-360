# Límites y reglas de interpretación

Aranjuez Limpio 360 está diseñado para hacer visibles los límites de la evidencia, no para ocultarlos.

## Reglas clave

### 1. Inventario histórico parcial ≠ censo actual
Los ocho antecedentes del MVP representan un mínimo documental confirmado dentro de las fuentes trabajadas. No se presentan como el total actual de puntos críticos de la Comuna 4.

### 2. IDENTIFICADO ≠ presencia actual
`IDENTIFICADO` describe la incorporación de un antecedente al MVP. No acredita que el fenómeno permanezca activo hoy.

### 3. Cero documental ≠ cero territorial
Que la precarga no acredite una observación, intervención o condición no significa que el hecho no exista o no haya ocurrido en el territorio.

### 4. Prioridad histórica ≠ prioridad del piloto
La prioridad consignada en el inventario de referencia se conserva como antecedente. No reemplaza una futura valoración realizada bajo la metodología del piloto.

### 5. Sin pin ≠ sin registro
Cuando no existe una coordenada única aprobada, el antecedente permanece visible y consultable desde el inventario. El sistema no fabrica una ubicación para poder mostrar un marcador.

### 6. Apoyo a decisión ≠ decisión automática
El módulo de priorización no utiliza puntaje oculto, pesos, ranking global ni posiciones 1–N. La revisión humana permanece explícita.

### 7. Prueba técnica ≠ validación comunitaria
Las pruebas ejecutadas hasta el cierre del Sprint 3 fueron internas y técnicas. No se afirma cocreación ni validación con comunidad o instituciones que no haya ocurrido.
